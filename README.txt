# Eslam TGD Portfolio

A lightweight cinematic portfolio starter.

## Run
Open `index.html` directly, or serve the folder with any static server.

## Replace
- `assets/profile.png` — your portrait is already included.
- Replace the CSS art placeholders with real project thumbnails/videos.
- Update social URLs and contact placeholders in `index.html`.

## Main structure
Hero + animated slider → Selected Work → About/Profile → Contact → Footer.

No fake testimonials, awards, clients, or years of experience are included.
